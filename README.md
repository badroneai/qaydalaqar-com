# qaydalaqar.com (قيد العقار)

Static landing page for **قيد العقار**.

## Deploy (GitHub Pages)
1) Push this repo to GitHub.
2) Enable GitHub Pages from branch `main` (or `master`) and root `/`.
3) Add custom domain `qaydalaqar.com`.
4) DNS at registrar:
   - Apex A records → GitHub Pages IPs
   - `www` CNAME → `badroneai.github.io`

Notes:
- SSL/HTTPS may take time after DNS changes.
